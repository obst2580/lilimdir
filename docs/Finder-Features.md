# Finder 기능 검토와 적용 상태

검토 기준: [Apple Finder 안내](https://support.apple.com/guide/mac-help/organize-your-files-in-the-finder-mchle9f0a1b2/27/mac/27), [Mac 단축키](https://support.apple.com/en-gb/102650), [Finder 태그 안내](https://support.apple.com/en-lb/guide/mac-help/mchlp15236/mac).

Lilim의 탐색기는 일반 파일 작업을 직접 처리하고, 파일 미리보기·기본 앱·공유·볼륨 추출은 macOS의 기능을 연결합니다.

| 기능 | 적용 상태와 동작 |
| --- | --- |
| 파일·폴더 탐색 | 파일과 폴더를 함께 표시. 컬럼을 깊이 제한 없이 확장하고 경로·방문 기록으로 이동 |
| 보기 방식 | 아이콘·목록·컬럼·갤러리. `⌘1`–`⌘4`, 설정 저장 |
| 정렬 | 이름·종류·크기·생성일·수정일, 오름/내림차순, 폴더 먼저 표시 |
| 다중 선택 | `⌘클릭`, `⇧클릭`, `⇧↑/↓`, `⌘A`. 부모 폴더와 자식을 함께 이동·복사할 때 중복 처리 방지 |
| 키보드 탐색 | 화살표, Home/End, 이름 첫 글자 입력, 선택 행으로 스크롤 |
| 복사·붙여넣기 | `⌘C`/`⌘V`, Finder와 파일 URL 클립보드 공유. 파일·폴더·가상본·심볼릭 링크 처리 |
| 이동 | 복사 후 `⌘⌥V`, 잘라내기 후 붙여넣기, 목적지 선택 메뉴 |
| 드래그 앤 드롭 | 파일 행·폴더·컬럼·사이드바 위치로 드롭. 같은 볼륨은 이동, 다른 볼륨은 복사. `⌥`는 복사, `⌘`는 이동 |
| 이름 충돌 | 둘 다 유지·대치·건너뛰기·취소. 대치 전 파일은 휴지통에 보관 |
| 삭제 | 시스템 휴지통으로 이동. 영구 삭제나 휴지통 비우기는 앱에서 제공하지 않음 |
| 실행 취소·다시 실행 | 복사·이동·휴지통·생성·이름 변경·복제·압축·가상본·태그·권한·잠금에 적용. `⌘Z`/`⌘⇧Z` |
| 새 폴더·파일 | `⌘⇧N`, 새 텍스트 파일, 선택 항목을 담은 새 폴더 |
| 이름 변경 | Return. 여러 항목은 텍스트 대치·접두/접미사·이름과 번호, 변경 전 미리보기 |
| 복제 | `⌘D`, 확장자 보존, 중복 이름 자동 구분 |
| 가상본 | Finder 호환 가상본 생성, 원본 보기, 폴더 가상본 탐색 |
| 압축 | 하나 또는 여러 항목을 ZIP으로 압축. 심볼릭 링크 보존 |
| 압축 해제 | ZIP 등을 기본 연결 앱으로 열어 macOS 압축 유틸리티 이용. 외부 앱 작업은 Lilim의 실행 취소에 포함하지 않음 |
| 파일 열기 | 더블클릭/`⌘O`, 기본 앱 또는 ‘다음으로 열기’에서 앱 선택 |
| 패키지·링크 | 패키지 내용 보기, 가상본·심볼릭 링크 원본 보기 |
| 훑어보기 | Space/`⌘Y`로 macOS Quick Look. 갤러리에도 같은 미리보기 사용 |
| 정보 가져오기 | `⌘I`, 종류·크기·폴더 내 파일 수·날짜·소유자·접근 권한·잠금·태그·경로 |
| 권한·잠금 | 정보 창에서 POSIX 권한과 잠금 변경, 실행 취소. 관리자 권한이나 소유권·ACL 편집은 제공하지 않음 |
| 태그 | 이름과 Finder 색상, 여러 항목에 추가/대치/전체 제거. 실행 취소 시 원래 태그 메타데이터 복원 |
| 공유 | macOS 공유 메뉴. 사용 가능한 AirDrop 등은 시스템과 설치 앱에 따라 표시 |
| 위치 | 홈·데스크탑·문서·다운로드·응용 프로그램·iCloud Drive, 즐겨찾기·최근 방문 |
| 즐겨찾기 | 상단 별·폴더/사이드바 우클릭·사이드바 +·메뉴 막대에서 추가/제거. 여러 폴더 추가, 중복 방지, 앱 재실행 후 저장 유지. 클릭 시 현재 터미널 탭에서 이동 |
| 외장·네트워크 볼륨 | 마운트된 위치 표시, 연결/해제 시 갱신, 추출 가능한 볼륨의 추출 버튼 |
| 검색 | 현재 폴더와 하위 폴더의 이름 검색, 숨김 파일 옵션, 결과 경로 표시 |
| 기타 | 경로 복사, Finder에서 선택 항목 보기, 현재 폴더 변경 감시, 작업 중 상태 표시·다음 항목부터 중단 |
| 터미널 결합 | 폴더 클릭은 현재 탭의 경로를 이동. 새 탭은 메뉴·버튼·`⌘T`로 명시적으로 생성 |

## 파일 작업의 복구 방식

복사 중인 항목은 목적지의 임시 폴더에서 완성한 뒤 최종 이름으로 옮깁니다. 중간에 실패한 복사본을 최종 파일처럼 노출하지 않습니다. 이동 실패 시 원본을 보존합니다. 자기 자신이나 하위 폴더로의 이동·복사는 차단하며, 목적지가 심볼릭 링크여도 검사합니다.

실행 취소는 이 실행 세션에서 Lilim이 수행한 작업을 기록합니다. 기존 경로에 다른 파일이 생기면 그 파일을 덮어쓰지 않고 중단하며, 충돌을 해결한 뒤 다시 실행 취소할 수 있습니다. 완료된 일부 항목만 있는 작업도 복구 기록을 남깁니다. 외부 앱·터미널에서 수행한 작업은 기록하지 않습니다. 앱을 종료하면 이 기록은 사라지며, 휴지통에 보관된 항목은 남습니다.

대용량 단일 파일의 복사와 ZIP 처리 중에는 현재 항목의 완료를 기다립니다. 상태줄의 중단 버튼은 항목 사이에 적용합니다. 바이트 단위 진행률은 제공하지 않습니다.

## macOS Finder에서 사용하는 기능

Spotlight 조건 검색·스마트 폴더 저장, 데스크탑 스택, Quick Actions·Automator, Finder 확장 메뉴, 클라우드 공급자의 다운로드/동기화 제어, 네트워크 서버 연결 설정, 디스크 관리, 소유권·ACL 편집은 Lilim 내부에 구현하지 않았습니다. **Finder에서 보기**로 현재 항목을 Finder에 선택해 이 기능을 사용할 수 있습니다. iCloud·외장·네트워크 위치의 일반 파일 작업은 해당 위치의 파일 시스템 권한과 상태를 따릅니다.

Lilim은 하나의 탐색기와 터미널 패널을 갖는 창을 유지합니다. Finder의 독립 탐색 창·탭·데스크탑 관리까지 복제한 상태는 아닙니다.

## 검증

`bash scripts/check.sh`는 앱 소유의 임시 파일만 이용합니다. 복사·이동·충돌 정책·대치/취소/재실행·부분 실패·심볼릭 링크·잘못된 이름·일괄 이름 변경·휴지통 복원·복원 경로 충돌·가상본·ZIP·태그·권한·잠금·파일 클립보드·선택 범위를 검사합니다. 기존 한글 터미널·PTY·현재 탭 이동·프롬프트 크기 변경 검사도 함께 실행합니다.

별도 검사 앱에서 복제, 실행 취소/다시 실행, 한글 이름 변경, Quick Look, 정보 보기, 드래그 이동과 복원, 갤러리, 다중 선택과 일괄 이름 변경, 검색창의 텍스트 실행 취소를 확인했습니다. 실제 외장 볼륨 추출이나 공유 전송은 수행하지 않았습니다.
