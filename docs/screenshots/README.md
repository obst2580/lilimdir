Images are native window captures, including macOS window decorations and indicators; they have not been reconstructed or retouched. UI labels are Korean. README translations describe the same screens and do not imply translated app UI.

The app icon is the project's own generated asset; its source and generation notes are in [App/Assets](../../App/Assets/README.md).
