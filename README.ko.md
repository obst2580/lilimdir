# Lilim

**폴더를 찾고, 명령을 실행하는 하나의 macOS 작업 창.**

[English](README.md) · [한국어](README.ko.md) · [日本語](README.ja.md)

Lilim은 Finder 방식의 파일 탐색기와 실제 터미널을 함께 제공합니다. 폴더를 클릭하면 **현재 터미널 탭**의 경로가 바뀌며, 셸·환경변수·출력 기록을 유지합니다. 별도의 세션이 필요할 때만 새 탭을 직접 엽니다.

SwiftUI·AppKit·네이티브 PTY 브리지로 구현했으며 외부 패키지 의존성이 없습니다. 청록색·민트색 포인트와 폴더·터미널을 결합한 아이콘을 사용합니다.

**현재 상태:** 개인용 초기 버전 0.1.0입니다. 직접 사용하며 불편과 오류를 개선하는 데 집중합니다. 판매·Mac App Store 출시 준비는 보류했습니다. 소스 저장소는 공개되어 있으며 오픈소스 라이선스는 아직 선택하지 않았습니다. **앱 UI는 현재 한국어**입니다. README의 세 언어 번역이 앱 UI의 세 언어 지원을 의미하지는 않습니다.

![계층 컬럼 탐색, 즐겨찾기와 오른쪽 터미널](docs/screenshots/workspace.png)

`Workspace → Projects → Garden`이 부모·자식 컬럼으로 펼쳐지고, 왼쪽에는 저장한 위치, 오른쪽에는 터미널 탭 하나가 보입니다. 모든 스크린샷은 2026년 10월 1일 실제 네이티브 앱에서 샘플 파일로 촬영했습니다. 촬영 세션의 셸 프롬프트는 간단하게 설정했습니다.

## 설치

### 필요한 환경

| 용도 | 조건 |
| --- | --- |
| 앱 실행 | macOS 14 이상 |
| 소스 빌드 | Swift 6.2 이상을 제공하는 macOS Command Line Tools 또는 Xcode |
| 범용 테스트 ZIP 생성 | 정식 Xcode 설치. Apple Silicon(`arm64`)·인텔(`x86_64`) 모두 빌드 |

### 빌드하고 실행하기

```sh
git clone https://github.com/obst2580/lilimdir.git
cd lilimdir
bash scripts/build-app.sh release
```

결과는 **`dist/Lilim.app`**입니다. Swift Package Manager 빌드는 로컬 도구의 아키텍처를 사용합니다. 인텔·Apple Silicon 모두 지원하는 앱은 아래 패키징 스크립트로 만듭니다. 일반 빌드는 외부 패키지 설치나 Xcode 프로젝트 생성이 필요하지 않습니다.

1. Finder에서 저장소의 `dist` 폴더를 엽니다.
2. `Lilim.app`을 **응용 프로그램** 폴더로 옮깁니다.
3. 설치한 앱을 더블클릭합니다.
4. Dock 아이콘을 우클릭하고 **옵션 → Dock에 유지**를 선택합니다.

업데이트할 때는 Lilim을 종료하고 새 앱으로 교체한 뒤 다시 실행합니다. 종료한 셸 세션은 복원하지 않습니다.

개발 중 실행하거나 시작 폴더를 지정하려면:

```sh
bash scripts/run.sh
bash scripts/run.sh --directory "$PWD"
```

현재 빌드는 로컬 ad hoc 서명만 포함하며 Developer ID 배포 서명·공증 전입니다. 다운로드한 테스트 앱은 다른 맥에서 실행이 차단될 수 있습니다. 포함된 설치 안내와 [Apple의 확인되지 않은 개발자 앱 안내](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac)를 확인하세요.

## 탐색과 즐겨찾기

| 화면 | 용도 |
| --- | --- |
| 사이드바 | 홈·데스크탑·문서·다운로드·응용 프로그램, 사용 가능한 볼륨, 즐겨찾기와 최근 방문 |
| 파일 탐색기 | 폴더와 파일을 아이콘·목록·계층 컬럼·갤러리로 표시 |
| 터미널 | 현재 셸 세션에서 선택한 폴더의 명령 실행 |

### 폴더 찾아가기

1. **폴더를 한 번 클릭**하면 해당 폴더로 들어가며 현재 터미널 경로도 바뀝니다. 컬럼 보기에서는 다음 컬럼에 하위 항목이 펼쳐집니다. 각 컬럼은 부모·자식 폴더를 나타내며 탐색 깊이는 3단계로 제한하지 않습니다.
2. 파일은 한 번 클릭해 선택하고 더블클릭해 기본 앱으로 엽니다. `⌘클릭`·`⇧클릭`으로 여러 항목을 선택합니다.
3. 경로 표시의 각 부분을 눌러 상위 위치로 이동합니다. `⌘L`·`⌘⇧G`로 경로를 입력하고, `⌘⇧O`로 폴더 선택 창을 엽니다.
4. `⌘F`는 현재 폴더와 하위 폴더에서 이름을 검색합니다. 결과에 부모 경로도 표시합니다.
5. `⌘1`–`⌘4`로 보기를 바꿉니다. 이름·종류·크기·생성일·수정일 정렬, 오름/내림차순, 폴더 먼저 표시를 지원합니다.
6. `⌘⇧.`으로 숨김 파일을 표시하고 `⌘R`로 새로고침합니다. 구분선을 드래그해 창의 영역 너비를 조절합니다.

폴더 심볼릭 링크도 Lilim 내부에서 탐색합니다. **Finder에서 보기**는 우클릭 메뉴에서 직접 선택하는 별도 동작입니다.

### 즐겨찾기 저장하기

- 탐색기 상단 **별**로 현재 폴더를 추가하거나 제거합니다.
- 폴더 우클릭 → **즐겨찾기에 추가**. 여러 폴더를 선택해 함께 추가할 수 있습니다.
- 사이드바 즐겨찾기 옆 **+**로 하나 또는 여러 폴더를 고릅니다. 현재 탐색 위치는 바꾸지 않습니다.
- 메뉴 막대 **즐겨찾기**에서도 폴더를 추가하거나 저장한 위치로 이동합니다.
- 저장한 위치를 우클릭해 제거합니다. 같은 경로의 중복 등록을 방지합니다.

즐겨찾기를 클릭하면 탐색기와 **현재 터미널 탭**이 이동합니다. 즐겨찾기와 최근 방문은 재실행 후에도 유지합니다. 현재는 평면 목록이며 사용자 그룹·별칭·수동 순서 편집은 지원하지 않습니다.

## 터미널 동작

| 조작 | 결과 |
| --- | --- |
| 폴더·경로 표시·즐겨찾기 클릭 | 현재 탭에서 이동. 새 탭을 만들거나 다른 탭으로 자동 전환하지 않음 |
| **+**, `⌘T`, **새 터미널 탭에서 열기** | 별도의 PTY와 셸 생성 |
| 터미널 탭 선택 | 해당 세션을 활성화하고 탐색기를 그 위치로 이동 |
| 명령이 실행 중일 때 폴더 선택 | 마지막 폴더 이동을 대기했다가 명령 종료 후 적용 |
| 터미널에서 `cd` 실행 | 터미널 경로 표시 갱신. 옆 화살표를 누르면 탐색기도 이동 |
| 탭 닫기 / 앱 종료 | 해당 세션의 셸·작업 종료 / 앱 소유 세션 전체 종료 |

다른 탭의 작업은 계속 실행됩니다. 실행 가능한 `$SHELL`을 로그인 셸로 사용하며, 없으면 `/bin/zsh`를 사용합니다. 폴더 이동은 경로를 안전하게 인용한 `builtin cd -- …` 명령으로 전달하므로 해당 명령이 화면에 보일 수 있습니다. 탐색기에서 이동할 때 입력 중이던 미완성 명령줄은 지웁니다.

UTF-8, 네이티브 입력기 연결, ANSI 색상·커서 이동·화면 지우기, 대체 화면, bracketed paste, 텍스트 선택·복사, 5,000행 스크롤백을 지원합니다. macOS 폴더명의 분해형 한글은 자모를 합친 음절로 표시하며 두 칸을 차지합니다. 원본 경로와 복사 문자열은 보존합니다.

Codex처럼 xterm 마우스 입력을 요청하는 프로그램에는 휠·트랙패드 스크롤을 전달합니다. 일반 셸 출력은 터미널의 스크롤백을 탐색합니다. Shift를 누르고 스크롤하면 사용 가능한 로컬 기록을 탐색합니다. 전체 화면 프로그램의 기록과 스크롤 위치는 해당 프로그램이 관리하며 Lilim의 스크롤백과 구분됩니다. 수정·검증 내용은 [터미널 스크롤 기록](docs/Terminal-Scrolling.md)에 있습니다.

![명시적으로 연 두 탭과 한글 경로·텍스트 출력](docs/screenshots/terminal-tabs.png)

즐겨찾기에서 `문서`를 새 탭으로 직접 열었습니다. 기존 `Garden` 탭을 유지하며 실제 셸에서 샘플 텍스트를 출력한 화면입니다.

## 파일 작업과 미리보기

선택 항목을 우클릭하거나 폴더 옵션 메뉴를 사용합니다. 파일 단축키는 **파일 탐색기에 포커스가 있을 때** 적용합니다. 터미널의 복사·붙여넣기는 터미널 입력으로 처리합니다.

| 분류 | 제공 기능 |
| --- | --- |
| 생성·열기 | 폴더, 텍스트 파일, 선택 항목으로 새 폴더, 기본 앱 열기, 다음으로 열기 |
| 복사·이동 | 복사/붙여넣기, 잘라내기, 이동 붙여넣기, 목적지 선택, 드래그 |
| 이름·복제 | 개별 이름 변경, 접두/접미사·대치·번호 방식의 일괄 변경과 미리보기, 복제 |
| 삭제·복구 | 시스템 휴지통, 현재 세션의 실행 취소·다시 실행 |
| 정리 | Finder 가상본, ZIP 생성, Finder 태그 이름·색상 및 추가/대치/제거 |
| 확인 | Quick Look, 갤러리, 파일 정보, 권한·잠금 상태 |
| 시스템 연결 | Finder에서 보기, 경로 복사, macOS 공유 창, 연결된 볼륨과 추출 |

### 복사·이동·복구

- `⌘C`로 복사하고 `⌘V`로 붙여넣습니다. `⌘⌥V`는 복사한 항목을 이동합니다. `⌘X`로도 이동 대상으로 지정할 수 있습니다.
- 같은 볼륨 안으로 드래그하면 이동하고 다른 볼륨으로 드래그하면 복사합니다. Option을 누르면 복사, Command를 누르면 이동합니다.
- 이름이 충돌하면 **둘 다 유지·대치·건너뛰기·취소**를 선택합니다. 대치 전 항목과 삭제 항목은 시스템 휴지통으로 보냅니다.
- `⌘Z`·`⌘⇧Z`로 지원되는 작업을 실행 취소·다시 실행합니다. 외부에서 항목을 바꾸거나 복원 경로가 충돌하면 복구가 제한될 수 있습니다. 기록은 앱 종료 시 초기화합니다.
- 영구 삭제와 휴지통 비우기는 제공하지 않습니다.

세부 구현·복구 범위는 [Finder 기능 검토](docs/Finder-Features.md)에 기록했습니다.

### 이름 변경과 미리보기

여러 항목을 선택하고 Return을 누르면 일괄 이름 변경 창을 엽니다. 적용 전 변경 전/후를 확인합니다. 확장자를 유지하며 목적지 이름이 충돌하면 작업을 시작하지 않습니다.

![두 파일에 demo 접두사를 붙이는 일괄 이름 변경 미리보기](docs/screenshots/batch-rename.png)

Space 또는 `⌘Y`로 Quick Look을 엽니다. 갤러리(`⌘4`)는 썸네일 위에 선택한 파일을 미리 보여줍니다. `⌘I` 정보 창에서 접근 권한과 잠금도 확인·변경할 수 있습니다.

![터미널 옆에서 샘플 README를 미리 보는 갤러리](docs/screenshots/gallery.png)

## 현재 제한 사항

- 터미널은 VT/xterm 명령의 일부를 구현했습니다. 복잡한 TUI·마우스 보고·emoji 조합의 완전한 호환성을 보장하지 않습니다.
- 검색은 **이름 검색**이며 내용 검색·전역 Spotlight 검색은 아닙니다. 최대 25,000개 항목을 조사하고 200개 결과를 표시하며 한도 도달을 상태줄에 알립니다. `node_modules`·`.git`·`.build`·`Library`·`Pods`·`DerivedData`·`.cache`, 링크 폴더와 앱 패키지 내부는 조사하지 않습니다.
- 선택한 폴더의 변경을 감시합니다. 다른 컬럼은 재탐색하거나 새로고침하면 갱신합니다.
- 하나의 파일 탐색 작업 창과 터미널 탭을 제공합니다. 독립된 두 파일 패널·파일 탐색 탭·여러 탐색 창은 구현하지 않았습니다.
- ZIP 생성은 지원하며 압축 파일 열기·해제는 외부 앱을 사용합니다. 가상 압축 탐색기·다중 작업 대기열·바이트 진행률·일시정지/재개·플러그인은 없습니다.
- 사용 가능한 iCloud 파일은 일반 파일로 접근하며 서비스별 동기화 제어는 구현하지 않았습니다.
- 즐겨찾기·최근 방문·마지막 폴더·보기·정렬을 저장합니다. 셸 세션과 파일 작업 실행 취소 기록은 재실행 후 복원하지 않습니다.
- App Store 샌드박스 실험에서 터미널 작업 제어와 사용자 CLI 실행 검사가 실패합니다. Store 대상은 **출시 가능한 상태가 아닙니다**.

<a id="development"></a>

## 개발

```sh
bash scripts/build-app.sh release
bash scripts/check.sh
```

검사는 독립 실행 파일로 빌드하며 앱 소유의 임시 데이터를 사용합니다. 파일 작업·충돌·복구·일괄 이름 변경·가상본·ZIP·태그·클립보드·선택·탐색·방문 기록·즐겨찾기·UTF-8/ANSI·분해형 한글·크기 변경과 실제 PTY 입력·경로 이동·Ctrl-C를 확인합니다. 현재 셸/환경변수 유지, 실행 중 명령의 이동 대기, 명시적으로만 새 탭 생성도 검사합니다.

| 경로 | 역할 |
| --- | --- |
| `Sources/Lilim/` | SwiftUI/AppKit UI, 탐색, 파일 작업, 터미널 렌더링 |
| `Sources/PTYBridge/` | C PTY 생성·크기 변경·작업 경로 조회 |
| `Tests/` | 파일·탐색·터미널·샌드박스 검사 |
| `App/` | 번들 정보, 개인정보 manifest, 아이콘 원본 |
| `scripts/` | 빌드·실행·아이콘·검사·패키징 |
| `Lilim.xcodeproj/` | Lilim·Lilim-AppStore 공유 Xcode scheme |
| `docs/` | 기능 검토·비교·스크린샷 |
| `Release/` | 이전 출시 검토와 공개하지 않은 페이지 초안 |
| `dist/`, `.build/` | 생성 결과. Git에서 제외 |

`TerminalBuffer`·`TerminalCanvasView`·`PTYProcess`가 해석·그리기·프로세스 관리를 나눕니다. 생성한 아이콘 원본과 색상은 [아이콘 기록](App/Assets/README.md)에 있습니다. `scripts/build-icon.sh`는 `.icns`와 사이드바 이미지를 만듭니다.

일반 Xcode scheme은 **Lilim**입니다. 소스를 추가/삭제하면 `python3 scripts/generate-xcode-project.py`로 참조를 갱신합니다. **Lilim-AppStore**는 샌드박스 실험용이며 개인 사용 빌드가 아닙니다. [출시 준비 상태](Release/Readiness.md)·[스토어 조사](docs/Mac-App-Store-Launch.md)·[Marta 비교](docs/Marta-Comparison.md)는 날짜가 있는 검토 기록이며 현재 출시 약속이 아닙니다.

## 테스트 버전 전달

정식 Xcode를 설치한 환경에서:

```sh
bash scripts/package-test-app.sh
```

현재 소스를 인텔·Apple Silicon용으로 Archive하고 로컬 서명을 적용합니다. **`INSTALL.txt`**(현재 한국어)를 포함한 ZIP을 생성한 뒤 실제 압축을 풀어 서명·아키텍처·설치 안내를 검증합니다. 결과:

```text
dist/Lilim-0.1.0-test-universal-YYYYMMDD-HHMMSS.zip
```

이 ZIP을 카카오톡 등으로 **파일 첨부**해 전달합니다. 받는 사람은 **맥에서** 다운로드·압축 해제 후 `Lilim.app`을 응용 프로그램으로 옮깁니다. Apple 배포 서명·공증 전 테스트 빌드입니다. 현재 GitHub Release에 공개 설치 파일은 없으며, 소스와 스크린샷은 설치 파일이 아닙니다.
