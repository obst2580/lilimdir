개인정보 처리 안내

운영자 명의와 문의처, 최종 출시 기능을 확정한 뒤 공개할 정책 초안입니다. 이 안내는 Lilim 앱의 데이터 처리에 대한 설명입니다.

Mac에서 처리하는 정보

Lilim은 사용자가 선택한 폴더의 파일명, 경로, 크기, 날짜와 태그 등을 파일 탐색과 관리에 사용합니다. 터미널의 입력과 출력은 앱 안에서 표시됩니다.

최근 방문 폴더, 즐겨찾기, 마지막 작업 위치와 보기 설정은 이 Mac에 저장됩니다. 샌드박스 버전은 사용자가 허용한 폴더의 접근 정보를 이 Mac에 보관해 다음 실행에 사용합니다. 셸 세션은 앱을 다시 시작할 때 복원하지 않습니다.

개발자에게 전송하는 정보

현재 Lilim 앱은 파일 내용·파일 경로·터미널 명령·출력을 개발자 서버로 전송하지 않습니다. 앱에 광고, 사용자 추적, 분석용 SDK 또는 별도 회원 가입 기능을 포함하지 않습니다.

사용자가 실행하는 명령

사용자가 실행한 명령이나 파일을 연 다른 앱은 해당 서비스의 동작에 따라 네트워크 통신을 수행할 수 있습니다. 예를 들어 원격 서버에 연결하는 명령의 데이터 처리는 그 명령과 연결한 서비스의 정책을 따릅니다.

구매와 지원 문의

App Store 구매를 제공하는 경우 결제와 구매 계정 정보는 Apple의 정책에 따라 처리됩니다. Lilim 앱은 카드 정보를 직접 입력받지 않습니다. 지원 문의를 보내면 사용자가 전달한 이메일과 문의 내용이 응답을 위해 처리될 수 있습니다. 실제 지원 서비스와 보관 기준은 출시 전에 확정합니다.

정책 변경과 문의

출시 앱의 데이터 처리 방식이 바뀌면 이 안내와 스토어 개인정보 정보를 갱신합니다.
