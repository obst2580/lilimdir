작업을 시작하는 방법

폴더 열기에서 작업할 폴더를 선택하세요. 파일은 클릭해서 선택하고, 두 번 클릭하면 기본 앱으로 열 수 있습니다. 폴더를 클릭하면 다음 위치로 이동합니다.

파일을 관리하려면

파일 목록에서 항목을 우클릭해 복사·이동·이름 변경·복제·휴지통을 선택하세요. ⌘클릭으로 여러 파일을 선택하고 ⇧클릭으로 연속된 항목을 선택할 수 있습니다.

  • 복사 ⌘C · 붙여넣기 ⌘V · 이동 붙여넣기 ⌘⌥V
  • 새 폴더 ⌘⇧N · 휴지통 ⌘⌫ · 이름 변경 Return
  • 파일 작업 실행 취소 ⌘Z · 다시 실행 ⌘⇧Z
  • 미리보기 Space · 정보 ⌘I · 폴더 안에서 검색 ⌘F

실행 취소 기록은 앱을 닫을 때 초기화됩니다. 복구할 파일이 외부에서 바뀌거나 같은 이름이 생기면 복구가 제한될 수 있습니다. 자세한 복구 범위는 출시 버전의 안내를 확인하세요.

터미널을 사용하려면

폴더 선택은 현재 열린 탭에서 이어집니다. 새 탭은 + 버튼, 우클릭 메뉴 또는 ⌘T로 엽니다. 다른 명령이 실행 중이면 폴더 이동은 명령이 끝날 때까지 대기합니다. 탭을 닫거나 앱을 종료하면 앱 소유의 셸과 작업이 종료됩니다.

터미널에 포커스를 옮기려면 ⌘Return을 누르세요. 글자 크기는 ⌘+와 ⌘-로 바꿀 수 있습니다. 복잡한 TUI·모든 VT 명령·마우스 보고·이모지 조합의 완전한 호환은 제공하지 않습니다.

App Store 시험판에서 일반 로컬 터미널의 작업 제어와 사용자 설치 CLI 실행에 제한이 확인됐습니다. 출시판의 지원 명령과 배포 경로는 검증 후 확정합니다.

문제가 생겼다면

앱 버전, macOS 버전, 수행한 작업과 표시된 오류를 적어 주세요. 폴더 접근 문제가 있으면 폴더 열기에서 위치를 다시 선택해 보세요. 명령 기록이나 파일 내용은 자동으로 개발자에게 전송되지 않습니다.
