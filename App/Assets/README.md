# Lilim app icon

Created with the built-in imagegen tool. The source PNG retains its alpha channel. The build script uses macOS sips and iconutil to package 16–1024 px representations into AppIcon.icns and a 256 px sidebar/Dock PNG.

## Final generation prompt

Use case: logo-brand.
Asset type: the final macOS application icon for Lilim, a native Finder plus terminal workspace.
Create ONE finished, polished app icon, square 1024 by 1024 canvas. Transparent pixels outside the icon silhouette.
Subject: a single integrated folder-and-terminal object. A generous mint/jade folder tab and folder body form the upper part of the mark; the front of the folder contains a dark evergreen terminal inset with a bold ivory chevron and underscore, exactly ">_". The folder and terminal read as one cohesive object, not two separate floating icons.
Style: refined native macOS app icon with softly rounded squircle silhouette, restrained tactile depth, subtle bevel and soft internal lighting. Front-facing, almost flat, precise geometry, thick simple shapes, beautiful at 32px and 16px. No tiny details.
Composition: icon centered, silhouette occupies approximately 86% of the canvas with equal transparent margins. The terminal prompt is large and central. Use an inviting saturated jade/teal body and pale mint folder detail, deep evergreen terminal interior, ivory prompt. Suggested palette teal #117C72, mint #6DD3C0, bright jade #18A88C, evergreen #131B1A, ivory #F3FAF7.
Constraints: one icon only, no mockup, no device, no surrounding presentation, no external drop shadow beyond the icon silhouette, no wordmark, no letters, no watermark. No purple, no gray-led palette, no neon glow, no blue-purple gradient. Preserve actual alpha transparency in the exterior; no white or checkerboard backdrop.

## Palette

- Light UI accent: #117C72, derived from OKLCH(0.53, 0.09, 184°).
- Dark UI accent: #6DD3C0, derived from OKLCH(0.80, 0.10, 180°).
- Terminal background: #131B1A.
- Terminal secondary surface: #1B2524.
- Terminal text: #DBECE9.
